# Cricket Player Purchase

A responsive cricket player purchasing web application built with
React, TypeScript, and Tailwind CSS.

## 🚀 Live Demo

[Live Demo](https://cricket-player-purchase.vercel.app/)

## 🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- Vite

## ✨ Features

- View available cricket players
- Select and purchase players
- Manage selected players
- Available and Selected player sections
- Dynamic player data
- Responsive design
- User-friendly interface
